# Mantine React Vite TypeScript Dashboard Template

A modern, scalable **dashboard template** built with **Mantine UI**, **React**, **Vite**, and **TypeScript**.  
Designed for rapid development, strong typing, and a clean architecture suitable for real-world applications.

---

## ✨ Features

- 📱 **Responsive Dashboard Layout**
- 🌙 **Dark / Light Mode** (Mantine theming)
- ⚡ **Vite** for ultra-fast development
- 🧠 **TypeScript-first** architecture
- 🎨 **Mantine UI v8**
- 📊 Charts & data tables ready
- 🧩 Modular & reusable components
- 🧪 Testing setup with Vitest & Testing Library
- 📘 Storybook integration
- 🎬 Animation-ready with Framer Motion

---

## 🛠️ Installation

To get started with this project, clone the repository and install the dependencies:

```bash
git clone https://github.com/your-username/mantine-react-vite-ts-dashboard-template.git
cd mantine-react-vite-ts-dashboard-template
npm install
```

## ▶️ Usage

To start the development server, run:

```bash
npm run dev
```

Open your browser and navigate to `http://localhost:5173` to see the application in action.

To build the project for production, run:

```bash
npm run build
```
